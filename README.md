# TriKiTok v2.0

**TriKiTok** lets you use your triki to scroll social media. It also lets you use it to control media volume.

---

## What's New in v2.0

* **Total UI Redesign:** Cleaner UI.
  
* **Top-Right Settings (🔧):** All configuration and language/theme pickers are organized behind the settings wrench icon.

* **8 Color Themes:** Choose from 8 color palettes via a dialog picker:

TikTok Pink 🌸

Ocean Blue 🌊

Sunset Orange 🌅

Emerald Green 🌿

Cyberpunk Purple ⚡

Neon Cyan 💎

Ruby Red 🥊

Midnight Gold ✨

* **Multilingual Support (PL / EN):** Switch between two avalivable languages.

* **Customizable Gesture Actions:** Configure what each gesture does (Rotate Clockwise Rotate Counter-Clockwise, Shake):

Scroll Down / Next Video ⬇️

Scroll Up / Previous Video ⬆️

Single Tap (Play / Pause) 👆

Double Tap (Like ❤️) 👆👆

Swipe Left ⬅️ / Swipe Right ➡️

Volume Up 🔊 / Volume Down 🔉

None (Disabled)

* **Haptic Feedback Tick:** -delicate system haptic feedback (`EFFECT_TICK`) on gesture execution.

* **Wake Lock (Keep Screen Awake):** toggle to keep the screen on while connected for hands- viewing.

* **Custom Bluetooth Device Name:** Configurable target device name.

* **Persistent Accessibility Service:** Configured with `stopWithTask="false"` to prevent the accessibility service from being killed when closing the app.

---

## Setup & First Run

1. **Grant Bluetooth Permissions:** Tap **Bluetooth Permissions** in the Home screen quick start card.

2. **Enable Accessibility Service:** Tap **Enable Accessibility Service** find **TriKiTok**, in your Android accessibility settings. Turn it on.

3. **Connect:** Wake up your Triki. Tap **Connect**.

4. **Open TikTok** and enjoy scrolling, volume control and media management!
